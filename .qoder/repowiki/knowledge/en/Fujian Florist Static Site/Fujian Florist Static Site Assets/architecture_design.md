Single-page static site centered on `index.html`, which loads Tailwind CSS via CDN, Google Fonts, Font Awesome, and the local `css/styles.css`. The page is organized into semantic `<section>` elements (funeral, wreaths, opening, association, graduation, pets, ceremonial, delivery, about, contact) each containing a grid container (`#funeral-products-grid`, etc.) that is populated at runtime by the `Products` module fetching from `products.json`. JavaScript is split into five independent IIFE modules loaded in dependency order: `cart.js` (localStorage-backed cart state), `translations.js` (i18n engine loading `translations.json`), `products.js` (product data fetch + card rendering), `components.js` (shared UI behaviors like toast, mobile menu, lightbox, cart sidebar), and `main.js` (orchestrates initialization, language switching, WhatsApp checkout link generation). Data flows one-way: `Products.load()` → `Products.renderAll()` → DOM mutation; `Cart` persists to `localStorage`; `Main` wires user actions to Cart/Products/Components. Asset directories `images/` and `components/` hold static resources; `.nojekyll` and `CNAME` configure GitHub Pages deployment.
