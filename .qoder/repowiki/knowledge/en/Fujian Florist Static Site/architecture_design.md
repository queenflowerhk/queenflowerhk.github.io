Single-repo static site served by Node (_serve.js) that renders multiple HTML pages (index, products, cart, about) sharing common JavaScript modules (components.js, cart.js, products.js, translations.js) loaded via fetch/inject. Product catalog is externalized into products.json and UI text into translations.json so content can be updated without touching code. CSS lives in docs/css/styles.css and assets in docs/images/. The .nojekyll file disables Jekyll processing on GitHub Pages, and CNAME configures the custom domain.
